另一执行入口：固定计划 RolloutRunner
RolloutRunner.run(row, plan, save)
→ 调用方预先给出 plan，本入口不调用 Planner
→ PlanInjection("query")：初态消息追加计划
→ PlanInjection("observation")：每次环境反馈追加计划
→ PlanInjection("thought")：助手续写前缀包含计划
→ plan=None：无计划执行

run_framework(mode="pe-s")
→ 在线调用一次 Planner
→ 计划作为独立 user 指导消息追加
→ 未使用 PlanInjection

两者共用 RolloutSession；计划来源和注入位置并不相同。
