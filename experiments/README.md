# 实验与证据

[高层规划器优化提案](../PROPOSAL.md)中的比较与流程仍为设计草案。下一步见[研究工作台](../RESEARCH.md#下一步)。

`src/planner-eval/` 作为 sub-repo 提供评估入口。原 D03、D05 等问题的未执行草案保存在[历史研究方案](../archive/pre-v04/RESEARCH.md#directions-current)。

研究者提供的现有训练基础、GPU 条件及投稿可行性判断见[投稿筛选约束](../RESEARCH.md#submission-constraints)。这些资源信息尚未在本仓库运行核验，不计作已完成实验。

## 保存方式

开始设计具体实验时创建 `<topic>/README.md`。方案、实现、配置、必要结果和分析围绕同一问题放在一起。按需增加文件，不预建空的代码或结果目录。

运行前说明本轮问题、工作假设、对照、测量方式、数据隔离与预算；可逆设计可以暂定，正式比较前固定协议与主要指标。系统原型应保留待研究机制需要的完整环节，学习收益不要求先由独立小实验确证。停止或扩大投入依据当前证据能覆盖的范围判断，沿用 [研究判断原则](../AGENTS.md#研究判断)。设计、已运行结果与分析分别标明，未执行的计划不能写成实验结论。

运行后链接实际代码与配置、模型和环境版本、prompt、采样参数、seed、硬件、预算及必要输出。尚无代码提交时注明本地版本状态。原始大产物保存在适合的位置，记录获取方式与核验方法，不把长日志复制进正文。

实验结果适合通过图表、对照或轨迹展示时，优先用可视化。把图或自包含 HTML 放在对应实验目录，由实验 README 链接。可视化注明比较口径和数据出处，便于回查原始记录。

## 判断与索引

- [同任务的高层战略采样](strategy-sampling/README.md)比较独立采样和提示探索其他路线，并用固定 Executor 检查路线是否在 ALFWorld 中实际发生。

比较成功率时同时检查计算和数据预算。候选方法的评价器训练、离线数据和额外调用也计入成本。报告多 seed 的波动，保留负结果和失败轨迹。具体实验要求见 [AGENTS.md](../AGENTS.md#实验)。

形成实际方案或实验记录后，在本页添加链接与一句话问题说明。有对应 Issue 或 PR 时，在记录中链接。任务范围与验收以 Issue 为准，配置和结果以实验记录为准，改变研究方向或假设去留的判断写回研究工作台。

高成本运行须先核对实际资源并取得明确授权。文档中的条件性安排不代表运行授权。
