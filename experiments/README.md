# 实验与证据

[方向题卡](../RESEARCH.md#direction-menu)已包含未执行的最小验证草案，尚未形成独立实验方案、实现或运行结果。原始 D01–D12 题卡的本轮审核已完成，定位统一见[审核结果](../RESEARCH.md#direction-menu)。后续实验随进一步筛选和明确的证据缺口确定；具体问题与前置条件见 [RESEARCH.md](../RESEARCH.md#下一步)。本目录不另建实验排期。

## 保存方式

开始设计具体实验时创建 `<topic>/README.md`。方案、实现、配置、必要结果和分析围绕同一问题放在一起。按需增加文件，不预建空的代码或结果目录。

运行前说明假设、主要变量、简单强基线、数据隔离、预算和 kill criterion。设计、已运行结果与分析分别标明，未执行的计划不能写成实验结论。

运行后链接实际代码与配置、模型和环境版本、prompt、采样参数、seed、硬件、预算及必要输出。尚无代码提交时注明本地版本状态。原始大产物保存在适合的位置，记录获取方式与核验方法，不把长日志复制进正文。

## 判断与索引

比较成功率时同时检查计算和数据预算。候选方法的评价器训练、离线数据和额外调用也计入成本。报告多 seed 的波动，保留负结果和失败轨迹。具体实验要求见 [AGENTS.md](../AGENTS.md#实验)。

形成实际方案或实验记录后，在本页添加链接与一句话问题说明。有对应 Issue 或 PR 时，在记录中链接。任务范围与验收以 Issue 为准，配置和结果以实验记录为准，改变研究方向或假设去留的判断写回研究工作台。

高成本运行须先核对实际资源并取得明确授权。文档中的条件性安排不代表运行授权。
