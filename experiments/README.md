# 实验与证据

本目录保存已运行实验的结果与证据。可运行的实验代码、配置和协议随 `src/recipe/<name>/` 维护。[研究工作台](../RESEARCH.md) · [工具集与 Recipe](../src/toolkit/README.md#基础库与-recipe)

## 保存方式

运行后在 `<topic>/README.md` 记录结果、适用限制和实际设置，并链接对应的 recipe。记录实际使用的代码、模型与环境版本、prompt、采样参数、seed、硬件、预算和必要输出的位置。尚无代码提交时注明本地版本状态。原始大产物保存在适合的位置，记录获取方式与核验方法。

实验结果适合通过图表、对照或轨迹展示时，优先用可视化。把图或自包含 HTML 放在对应实验目录，由实验 README 链接。可视化注明比较口径和数据出处，便于回查原始记录。

## 判断与索引

- [同任务的高层战略采样](strategy-sampling/README.md)比较独立采样和提示探索其他路线，并用固定 Executor 检查路线是否在 ALFWorld 中实际发生。
- [Planner-Centered v2](planner-centered-v2/README.md)记录独立的未训练框架性能测试协议和单任务接口验收：五配置成功、PC-F 协议错误缺评，正式矩阵待冻结。
- [旧四框架对照评测](planner-centered/README.md)保留 ALFWorld 完整测试集结果、四套环境的已有评分，以及接口验收与交互轨迹。

比较成功率时同时检查计算和数据预算。候选方法的评价器训练、离线数据和额外调用也计入成本。报告多 seed 的波动，保留负结果和失败轨迹。具体实验要求见 [AGENTS.md](../AGENTS.md#实验)。

形成实验结果后，在本页添加链接和一句话问题说明。有对应 Issue 或 PR 时，在记录中链接。
