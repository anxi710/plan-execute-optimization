## 保存方式

需要形成独立论文笔记时创建 `<paper>/README.md`，记录完整标题、版本、一手来源，以及本次阅读要回答的问题。局部核查可留在研究工作台并记录来源与深度。相关论文较多时再按主题分组，不预建分类目录。

笔记按论文类型与阅读目的组织。保留可定位的原文或代码位置，区分论文结论、本项目推断与未知项。方法论文重点核查机制及训练和评估设置；诊断论文重点核查测量与替代解释；benchmark 重点核查任务、划分和评测协议。

实质阅读后说明原有疑问、判断变化与停止理由。证据足够即停止，剩余缺口需要实验时写回研究工作台，不自动扩大阅读范围。

## 索引规则

形成实际笔记后，在本页添加链接和一句话说明：它帮助回答了哪个问题。有对应 Issue 或 PR 时，在笔记中链接，不复制任务卡。待核实的论文名称不能写成已阅读成果。原文按可合法获取的来源保存。
